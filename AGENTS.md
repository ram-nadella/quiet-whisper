# AGENTS.md

Orientation for agents working in this repo. Read this end-to-end before changing anything.

## What this project is

**Quiet Whisper** — a calm, paper-textured local dictation app for macOS. The user opens a window, presses one button (or holds space), speaks, and the words appear as editable text. History groups by date in a collapsible sidebar. Everything stays on-device.

Two things live in this repo:

- `design_handoff_quiet_whisper/` — the **design spec**. A high-fidelity React/HTML prototype with a comprehensive README. **This is the source of truth for visual design, copy, motion, and behavior.** Read it before designing anything new.
- `QuietWhisper/` — the **production SwiftUI app**. Recreates the prototype natively.

`docs/plans/` keeps prior implementation plans for context.

## Build & run

The Xcode project is generated from [`project.yml`](QuietWhisper/project.yml). **After adding, removing, or renaming any source file, you must regenerate.**

```bash
# Prerequisites (install once)
brew install xcodegen

# Regenerate the .xcodeproj after any file-tree change
cd QuietWhisper
xcodegen generate

# Build (Debug)
xcodebuild -project QuietWhisper.xcodeproj -scheme QuietWhisper \
  -configuration Debug -destination 'platform=macOS' build

# Run from the built bundle
open ~/Library/Developer/Xcode/DerivedData/QuietWhisper-*/Build/Products/Debug/QuietWhisper.app
```

Day-to-day: open `QuietWhisper.xcodeproj` in Xcode and hit Run (⌘R). If you only edited existing files (no add/remove), you don't need to regenerate.

**Deployment target:** macOS 14 (Sonoma). Required by SwiftData. Apple Silicon recommended; Intel works but WhisperKit runs on CPU.

## Dependencies

- **WhisperKit** (SPM, ≥ 0.10.0) — on-device Whisper inference. Pinned in `project.yml` under `packages:`.
- **No others.** No analytics, no crash reporters, no UI libraries. Stay lean.

## Design system — the rules

The README in `design_handoff_quiet_whisper/` is canonical. The short version:

### Aesthetic
> "Paper." Off-white surfaces, ink as the only color, generous whitespace, serif display type. The app should feel like opening a notebook, not launching an app.

**No** gradients, glows, glassmorphism, or decorative iconography. **No** pure black or pure white anywhere — both themes are warm. The single moment of warmth is the live waveform during recording.

### Color tokens — use `@Environment(\.paperTheme) var theme`

All colors come from `PaperTheme` ([Theme/PaperTheme.swift](QuietWhisper/QuietWhisper/Theme/PaperTheme.swift)). Two static instances: `.light` and `.dark`. **Never hardcode hex values in views** — read from `theme.bg`, `theme.ink`, `theme.mute`, etc. Full token list: `bg, panel, panelSoft, sidebar, ink, inkSoft, mute, muteSoft, line, lineSoft, hover, active, selected, recordBg, recordFg, dotIdle, dotActive, danger`.

If you need a token that doesn't exist, add it to **both** `.light` and `.dark` in `PaperTheme.swift` — never as a one-off in a view.

### Typography — use `Font` extensions

All fonts come from `Font` extensions in [Theme/Typography.swift](QuietWhisper/QuietWhisper/Theme/Typography.swift): `.paperHero`, `.paperEditorTitle`, `.paperEditorBody`, `.paperMetaMono`, `.paperEyebrowMono`, etc. Currently mapped to system fonts (New York / SF Pro / SF Mono) — substitution is allowed by the README. To swap to bundled Fraunces / Inter / JetBrains Mono later: drop TTFs in `Resources/Fonts/`, restore [Theme/FontRegistry.swift](QuietWhisper/QuietWhisper/Theme/FontRegistry.swift) registration, point the extensions at `Font.custom(...)`.

### Icons — use `PaperIcon`

Stroke SVG icons live in [Theme/Icons.swift](QuietWhisper/QuietWhisper/Theme/Icons.swift) as `PaperIcon.Sidebar()`, `PaperIcon.Settings()`, etc. **Do not use SF Symbols.** The icons are deliberately custom; they're what makes the chrome feel quiet.

### Motion (timings to match)

- Sidebar slide: 260 ms `cubic-bezier(.4,0,.2,1)` (use `.easeInOut(duration: 0.26)`)
- Theme swap: 240 ms ease
- Record button morph: 220 ms ease
- IconButton hover: 120 ms ease
- Modal enter: 200 ms cubic-bezier
- Listening dot pulse: 1.4 s ease-in-out infinite (opacity 0.3↔0.9, scale 1↔1.25)

These are not approximate. The README spells them out verbatim — match them.

## State machine

```
idle ──[click record / press space]──> recording
recording ──[click stop / release space]──> transcribing
transcribing ──[engine returns text]──> idle (with new snippet selected)
```

Lives in [Views/ContentView.swift](QuietWhisper/QuietWhisper/Views/ContentView.swift). Hold-space rules in [Input/SpaceKeyMonitor.swift](QuietWhisper/QuietWhisper/Input/SpaceKeyMonitor.swift) — match the prototype's logic exactly (no repeats, no fire when typing, no fire when settings open).

## Conventions specific to this app

### Do
- Read `design_handoff_quiet_whisper/README.md` before designing anything new.
- Match the prototype's tokens, sizes, copy, and timings **verbatim**. The design has been thought through.
- Use `@Environment(\.paperTheme) private var theme` for colors.
- Keep views presentational; pass state in via init args, not `@Query` or `@AppStorage` directly (exception: `ContentView` is the integration layer and owns the data fetches).
- Add new shared types to [APIContracts.swift](QuietWhisper/QuietWhisper/APIContracts.swift) — that file is the public surface that all subdirectories code against.

### Don't
- Don't add a `MenuBarExtra`, global hotkey, or any system-wide UI. The app exists in its window and only its window.
- Don't add network calls beyond WhisperKit's model download. No telemetry, no crash reporting that ships transcripts.
- Don't retain audio after transcription completes. The temp WAV is deleted in `ContentView.stopRecording`.
- Don't introduce a UI library, CSS-in-Swift framework, or design-system abstraction. The 30 files here are deliberately small and direct.
- Don't add features the README's "what NOT to do" list rules out: markdown mode, summarization, AI rewrite, tags, audio playback, streaming transcription, pause/resume, decorative icons, gradients (except the editor footer fade), glassmorphism, the `bars`/`blob` waveform variants.
- Don't use SF Symbols or emoji.
- Don't hand-edit `QuietWhisper.xcodeproj/project.pbxproj` or `Info.plist` — they're generated. Edit `project.yml` instead, then `xcodegen generate`.
- Don't write multi-line docstrings or block comments. Per repo style, comments only when the *why* is non-obvious.

## Common tasks

### Add a new view
1. Create the file under `Views/{Components,Stages,Sidebar,Settings}/`.
2. Use `@Environment(\.paperTheme) private var theme`.
3. Reference existing components rather than redefining (e.g., use `IconButton`, `DotWave`, `RecordButton`).
4. `cd QuietWhisper && xcodegen generate` to pick it up.

### Add a setting
1. Add the field to `AppSettings` in [Models/AppSettings.swift](QuietWhisper/QuietWhisper/Models/AppSettings.swift) with a `qw.<key>` UserDefaults key.
2. Add a `SettingGroup` + appropriate row (`ToggleRow` / `ModelRow` / `SelectRow`) to [Views/Settings/SettingsModal.swift](QuietWhisper/QuietWhisper/Views/Settings/SettingsModal.swift).
3. If it's user-visible copy, mirror the prototype's tone — short, italic-serif hints under each label.

### Change a color
Edit **both** `.light` and `.dark` in [Theme/PaperTheme.swift](QuietWhisper/QuietWhisper/Theme/PaperTheme.swift). Verify the constraint: warm, no pure black/white.

### Add a new icon
Add a new struct to `PaperIcon` in [Theme/Icons.swift](QuietWhisper/QuietWhisper/Theme/Icons.swift), 16×16 viewBox, stroke-only, round caps/joins, stroke-width matching the existing icons (1.1–1.5 depending on density).

### Add a new snippet field
1. Add the property to `Snippet` in [Models/Snippet.swift](QuietWhisper/QuietWhisper/Models/Snippet.swift).
2. SwiftData will migrate automatically for additive changes; for removals/renames, add a `MigrationPlan`.
3. Wire it through `EditorStage` if user-editable.

## Verification checklist (the README's "what done looks like")

- [ ] App launches to empty state (or last opened snippet, if any)
- [ ] Click record OR hold space → live waveform → release → transcript appears in 1–3s for ≤1 min audio
- [ ] Transcript is editable in place; edits persist immediately (300 ms debounced autosave)
- [ ] Sidebar lists notes grouped by Today / Yesterday / This week / Earlier
- [ ] Sidebar item delete works with the 2-click confirm
- [ ] Settings modal lets you pick a model and toggle auto-punct + dark mode
- [ ] Light/dark theme swap is animated and smooth (240 ms)
- [ ] No network calls happen during normal operation (verify with Little Snitch — only WhisperKit model download is allowed)

## Known FIXMEs / open work

- **WhisperKit API shape**: Two `// FIXME(whisperkit-api):` markers in [Audio/Transcriber.swift](QuietWhisper/QuietWhisper/Audio/Transcriber.swift). The call signatures compiled but should be verified end-to-end against the resolved 0.10.x version on a real transcribe.
- **Voxtral row**: Currently disabled (`isAvailable = false` in `WhisperModelKind`). Re-enable when a local Voxtral runtime ships.
- **Fonts**: Using system New York / SF Pro / SF Mono. Bundling Fraunces statics is a v2 swap — pure `Typography.swift` edit, no API change.
- **Sendable warning**: One `AVAudioPCMBuffer` non-Sendable warning in [Audio/Recorder.swift](QuietWhisper/QuietWhisper/Audio/Recorder.swift). Cosmetic for now; address by adopting `@preconcurrency` on the AVFAudio import or restructuring the tap closure.
- **Visual diff**: The prototype's `screenshots/0X-*.png` were not used as visual regression baselines. Compare against them when the app is functionally complete.

## v2 / out of scope (per README)

- Markdown mode in the editor body
- Multi-language transcription
- Audio retention / playback
- Streaming transcription (currently batch)
- Pause/resume mid-recording
- Custom global hotkey

## When in doubt

The prototype is the spec. If you're unsure about a token, padding, copy, or timing, **find it in the prototype** before inventing. The order to check:

1. `design_handoff_quiet_whisper/README.md` (the description)
2. `design_handoff_quiet_whisper/prototype/qw-*.jsx` (the working reference)
3. `design_handoff_quiet_whisper/screenshots/*.png` (the visual truth)

If it's still unclear after all three, ask the user — don't guess.
